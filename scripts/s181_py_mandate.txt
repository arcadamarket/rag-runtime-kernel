Rule 31 (PY-SCRIPT-MANDATE -- S180 operator directive, promoted to a governed rule S181). THE MANDATE: anything that CAN be a Python script MUST be one. A procedure that exists only as prose -- in a runbook, a blueprint, a session summary, or an agent's working memory -- is re-derived from scratch by every successor, drifts silently from the facts underneath it, and is covered by no test and no auditor. A procedure that exists as a script is versioned, diffable, testable, registrable as a baked asset, and callable by any future session without being understood first. WHAT QUALIFIES: any sequence the agent would otherwise perform by hand more than once -- measurements, comparisons, migrations, backfills, reconciliations, report renders, environment probes, cleanup passes. If the agent is about to run the same shaped command three times with different arguments, that is a script it has not written yet. WHAT DOES NOT: one-off exploratory reads, and genuine judgement calls, which are the operator's. THE RECIPROCAL, AND THE REASON THIS IS A RULE RATHER THAN ADVICE (E-092): no control is required of a clone that is not first operating in the source. A script this kernel mandates but does not itself run is advice with a citation. Therefore a mandate promoted into the universal INIT spec must ALREADY be operating here, and the reuse registry is how that is checked: a script that is not registered is invisible to reuse-check and will be rewritten (Rule 25). WORKFLOW: reuse-check BEFORE authoring; author under the project root, never in a temp dir that dies with the session; register-asset with a real purpose line, not a placeholder; and prefer a governed kernel verb over a loose script whenever the operation touches canonical state, because a script that writes the RAG outside the guarded store violates tool_contract no matter how well written it is. DECIDABLE PREDICATE: every multi-step procedure this deployment relies on resolves to a registered asset or a kernel verb; a procedure that exists only as prose in a document is a finding, not a practice.
